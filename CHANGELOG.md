# Changelog

## 0.1.3

* The seafront moves again in the desktop app: the palm trees sway, the water shimmers and the birds fly. The desktop app draws still a scene holding a media query, but for reduced motion, so the scenes hold no other: on a window taller than wide, the scene is no longer brought in from the edges.
* The scene follows the app's light or dark mode with `light-dark()` colors instead of a `prefers-color-scheme` query.
* The scene keeps all its styles in its style sheet, none in style attributes.

## 0.1.2

* The plugin has the Miami '26 icon of the VS Code and Visual Studio themes: the sunset and palm tile, square at 512 px.

## 0.1.1

* `/miami26 still` shows the Miami colors alone, without the seafront. The prompt box no longer sits as a solid block over a plain gradient.

## 0.1.0

* The Bay and Sunset palettes of the VS Code and Visual Studio themes, each in dark and light, for the whole Claude desktop app.
* An animated Miami seafront behind the conversation: pastel towers across the bay, a Deco hotel with a neon fin, palm trees swaying, birds and clouds drifting.
* `/miami26 bay | sunset | scene | still | off` to switch.
